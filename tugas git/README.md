# Sistem Informasi Persediaan - Fitur Barang Keluar

Aplikasi ini adalah simulasi sederhana menggunakan Java untuk memvalidasi pengeluaran stok barang.

## Cara Menjalankan Unit Test (JUnit)
1. Buka folder proyek di Visual Studio Code.
2. Pastikan file `Persediaan.java` dan `PersediaanTest.java` berada di direktori yang sama.
3. Pastikan ekstensi "Test Runner for Java" sudah terinstal dan JUnit 5 sudah ditambahkan ke *classpath*.
4. Buka file `PersediaanTest.java`.
5. Klik ikon "Run Test" di atas deklarasi fungsi atau gunakan tab "Testing" di panel sebelah kiri VSCode untuk menjalankan keenam skenario pengujian.
6. Hasil pengujian (Lulus/Gagal) akan muncul di panel Test Explorer.
